# The DSP module of the playground

`aica_dsp_core.wasm` and `aica_dsp_core.mjs` are not written in this repository. They are the AICA DSP core of
the Dreamcast emulator nullDC 3.0.0 (repository `skmp/nulldc3`, `libswirl/hw/aica/dsp_core`), the same core the
emulator's sound chip and its debugger run, compiled to WebAssembly by the emulator's
`libswirl/hw/aica/dsp_core/wasm/build.sh`: `aica_dsp_core.wasm` is its output, `aica_dsp_core.mjs` its loader,
copied as it is. `PROVENANCE.json` names the emulator commit they were built from, the last commit of the core,
the emscripten version and the size and sha256 of both files.

They are regenerated by `npm run build:dspsim -- --emulator <emulator tree>` (`scripts/build-dspsim.ts`), which
also writes `PROVENANCE.json` and `known-answers.json` (the native core's answers to its known-answer programs,
which `src/lib/aicaDspKnown.test.ts` holds the module to). `aica_dsp_core.d.mts`, the loader's declarations, is
written by hand in this repository.
